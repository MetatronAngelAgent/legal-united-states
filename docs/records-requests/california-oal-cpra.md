# California Public Records Act request — California Code of Regulations

**To:** Office of Administrative Law, 300 Capitol Mall, Suite 1250, Sacramento, CA 95814-4339 · staff@oal.ca.gov
**Subject:** California Public Records Act request — electronic copy of the California Code of Regulations

Dear Records Coordinator,

Under the California Public Records Act (Gov. Code § 7920.000 et seq.), I request copies of the following records:

1. The complete current text of the California Code of Regulations (all titles, including Title 24 if held), in whatever electronic format OAL holds or receives it — for example XML, SGML, HTML, Word or other database exports, including any files delivered to OAL by its official publisher.
2. Any record showing the date through which that text is current (e.g. the Register number).
3. The current contract or agreement between OAL and its official CCR publisher (Barclays / Thomson Reuters), including any terms on public access to, or redistribution of, the electronic text.

Under Gov. Code § 7922.570, please provide records held in an electronic format in that format, or in any electronic format the agency uses. Electronic delivery (download link or email) is preferred, which should avoid copying costs. If any part of the request is denied, please cite the specific exemption and release all segregable portions.

I am requesting these records for non-commercial research: an open, searchable collection of U.S. law. Please let me know in advance if fees will exceed $50.

Thank you. I look forward to your determination within 10 days as provided by Gov. Code § 7922.535.
